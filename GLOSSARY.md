# Wisdom Quotes

Wisdom Quotes manages a personal collection of quotes. This glossary defines the language used for preserving and recovering that collection.

## Language

**Quote backup**:
A saved copy of a quote collection at a particular point in time, available for later recovery.
_Avoid_: Sync, cloud mirror

**Quote restore**:
A user-requested replacement of the current quote collection with the collection in a selected quote backup.
_Avoid_: Sync

**Backup version**:
An independently saved quote backup representing the complete collection at one point in time. A later backup does not replace an earlier version.
_Avoid_: Latest cloud state
